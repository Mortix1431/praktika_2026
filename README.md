# praktika_2026 — база знаний по MultiCAD API

Конспекты и примеры по разработке плагинов для nanoCAD / MultiCAD (Магма-Компьютер,
курс MultiCAD.NET / C++). Практика ведётся на **C++**.

## Как продолжить в новой сессии

Если начат новый чат — скажи ассистенту:
> «Продолжаем практику MultiCAD на C++. База знаний — в этом репозитории
> (`docs/`, `examples/`). Наш файл задания — `task_nosenko.cpp`. Веди журнал в
> `docs/worklog.md`.»

Ассистент прочитает файлы и подхватит контекст — пересказывать всё заново не нужно.

## Структура

- **`docs/`** — конспекты (см. оглавление в `docs/worklog.md`):
  - стандарт кодирования, иерархия классов, базовые типы и контейнеры,
    умные указатели;
  - сервисы (Context, Native Gate, Object Manager, Documents Manager);
  - работа с чертежом, идентификация/приведение типов, объектные связи,
    структура объектов, флаги команд, листовое тело;
  - `dev_environment.md` — среда (SVN, сборка, отладка, коммиты);
  - `worklog.md` — журнал «что сделано» по дням.
- **`examples/`** — примеры кода (C++ и C#): команды `SampleCmd*`, `test_LVA`,
  `SimpleSheetSolid`, работа с объектами, реакторы и т.д.

## Ключевые договорённости

- Язык практики: **C++**. Файл задания: **`task_nosenko.cpp`** (в SVN — `CPP.2024`).
- Соблюдаем корпоративный стандарт (`docs/coding_standard.md`): без STL,
  исключений, классической рекурсии; умные указатели `MObjPtr`; проверка
  указателей; табы; префиксы `m_`/`s_`/`g`; комментарии-разделители на русском.
- Коммиты в SVN — чисто, без лишних пустых строк.
- В конце каждой сессии — запись в `docs/worklog.md`.

## Среда (кратко)

SVN-песочница `…/MechaniCS25.45xx/AutoTests/Sources/_Sandbox` → `CPP.2024` →
`SandboxCpp.sln` (retarget → Cancel) → сборка `SandboxCpp.dll` → F5 (nanoCAD +
отладчик, автозагрузка через `AutoloadModules.mcx`). Подробно — `docs/dev_environment.md`.
