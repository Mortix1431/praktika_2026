## Таблицы — команды и диалог

Команды командной строки:
- `SPTABLE` (ТАБЛИЦЫ) — создание/вставка таблицы.
- `SPTABLEEXCELEXPORT` (ЭКСПОРТ ТАБЛИЦЫ В EXCEL) — экспорт таблицы в Excel.

### Диалог «Создание таблицы»
Тип источника:
- Нестандартная
- Загрузить из базы
- Загрузить из файла
- Отчёт по выборке объектов
- Импортировать из Excel
- Из буфера обмена

Параметры структуры (пример из демо):
- Наименование — заголовок таблицы.
- Колонки — `25 × 5`.
- Строки:
  - Верхний колонтитул — `12 × 0`
  - Данные — `8 × 3`
  - Нижний колонтитул — `12 × 0`
- Флаги: «Строки снизу вверх», «Добавить формат».

Программный аналог — класс `McTable` (`Multicad.Symbols.Tables`), см.
`multicad_net_2d.md`.

## MultiCAD в других платформах

- Те же объекты оформления/таблицы работают в **MechaniCS** под Autodesk
  Inventor Professional 2023 (вкладка ленты «MechaniCS Оборудование»:
  «Редактор спецификации», «Таблицы», «Тех. требования», «Тех. характеристики»).
- Используется ГОСТ-оформление листа (GOST Border, GOST Form 1, основная надпись
  «Изм/Лист/№ докум/Подп/Дата», «Разраб./Пров./Т.контр.»).
- Подтверждает кросс-платформенность из конспекта: один код объектов работает в
  nanoCAD, AutoCAD/Inventor (через СПДС GraphiCS / MechaniCS), ZWCAD.
