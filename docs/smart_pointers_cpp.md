# Умные указатели MultiCAD (C++)

Конспект видеоурока. Связано с корпоративным стандартом, п. 5.e: работа с
динамически создаваемыми объектами выполняется через указатели-шаблоны,
автоматически уничтожающие объект.

## Шаблон MObjPtr<T>

Базовый умный указатель — шаблон `MObjPtr<T>`. Для конкретных интерфейсов
заведены typedef'ы вида `IMc…Ptr`:

| Умный указатель | = | Шаблон |
|---|---|---|
| `IMcObjectPtr` | `MObjPtr<IMcObject>` | |
| `IMcLinePtr` | `MObjPtr<IMcLine>` | |
| `IMcDbEntityPtr` | `MObjPtr<IMcDbEntity>` | |
| `IMcsGraphicsPtr` | `MObjPtr<IMcsGraphics>` | |

Это COM-подобный умный указатель: владеет объектом через счётчик ссылок и
освобождает его в деструкторе (своевременное уничтожение без ручного `delete`).

## Члены и методы

- **`.p`** — «сырой» (raw) указатель на интерфейс внутри умного указателя.
- **`.Attach(T* p)`** — забрать владение готовым «сырым» указателем (без
  дополнительного увеличения счётчика ссылок).
- **`operator =`** — присваивание из другого умного указателя, из «сырого»
  указателя или из указателя другого интерфейса. При присваивании из другого
  интерфейса выполняется **приведение интерфейса** (по сути `QueryInterface`),
  а не простое копирование адреса.

## Способы получить/преобразовать указатель

```cpp
// 1. Создание объекта — менеджер возвращает умный указатель
IMcObjectPtr pMcO = gpMcObjManager->createObject(IID_IMcLine);

// 2. Приведение интерфейса присваиванием умных указателей
IMcLinePtr pL = pMcO;          // IMcObject -> IMcLine (как QueryInterface)

// 3. Доступ к "сырому" указателю
IMcObject* _pMcO = pMcO.p;

// 4. Приведение "сырых" указателей
IMcLine* _pL = dynamic_cast<IMcLine*>(_pMcO);   // безопасно
// IMcLine* _pL = (IMcLine*)_pMcO;              // C-style — избегать
```

## Три способа поместить «сырой» указатель в умный — важно различать

```cpp
IMcsGraphicsPtr pG;

pG.Attach(gpMcContext->GetGraphics()); // забрать владение БЕЗ доп. AddRef
pG = gpMcContext->GetGraphics();        // присваивание: приведение/AddRef
pG.p = gpMcContext->GetGraphics();      // прямая запись в .p — владение НЕ берётся
```

- `Attach` — корректно, когда функция уже вернула указатель с «нашей» ссылкой.
- `operator =` — безопасный универсальный способ.
- `pG.p = …` — пишет напрямую в поле, минуя логику счётчика ссылок: предыдущий
  объект не освобождается, новый не захватывается → потенциальная утечка/двойное
  освобождение. Использовать осознанно.

## Связь с сервисами

В примере указатели приходят из глобальных сервисов:
- `gpMcObjManager->createObject(IID_…)` — менеджер объектов.
- `gpMcContext->GetGraphics()` — графика через контекст; интерфейс
  `IMcsGraphics : public IMObject`, метод объявлен в `IMcNativeGate`
  (`GetGraphics()`), методы шлюза дублируются в `IContext`.
